# dupfind 第 1 版实现计划

依据：`docs/superpowers/specs/2026-10-20-dupfind-design.md`  
本计划只覆盖第 1 版。不做删除、相似图片、图形界面、打包 exe。

## 任务 1：命令行入口

文件：`dupfind.py`

- 用标准库 `argparse`
- 位置参数：文件夹路径
- 可选：`--min-size`，默认 `1`
- `-h` 帮助为中文
- 路径不存在或不是文件夹：打印中文错误，`sys.exit(2)`
- 解析 `--min-size`：`123` / `1kb` / `1mb` / `1gb`（大小写不敏感）。非法值退出码 2

验证：`python dupfind.py -h` 能显示用法；对不存在的路径退出码为 2。

## 任务 2：扫描和按大小分组

仍在 `dupfind.py`

- `os.walk(followlinks=False)`
- 只处理普通文件
- 0 字节跳过
- 小于 `--min-size` 跳过
- `os.stat` / 打开失败：计入 skipped，继续
- 进度：每处理若干文件打印已扫描数量（打到 stderr，避免污染最终结果）
- 返回：`size -> [绝对路径, ...]`，以及扫描数、跳过数

验证：对一个只有不同大小文件的文件夹，不应进入哈希。

## 任务 3：哈希和重复分组

仍在 `dupfind.py`

- 只对「同一大小、至少 2 个文件」算 SHA-256
- 分块读取，块大小 `1024 * 1024`
- 哈希相同且至少 2 个路径 -> 一组
- 浪费空间 = 每组 `(n - 1) * size`
- 组按浪费空间从大到小排序

验证：两个内容相同的拷贝被分到一组；两个同样大小但内容不同的文件不会成组。

## 任务 4：中文输出

仍在 `dupfind.py`

- 无重复：打印「没有发现重复文件」，退出 0
- 有重复：先摘要（扫描数、跳过数、组数、多占空间），再打印各组绝对路径
- 未预期异常：中文错误，退出 1
- 主入口用 `if __name__ == "__main__"`

验证：输出和设计文档示例结构一致。

## 任务 5：本地试跑

在临时文件夹里放：

- `a.txt` 和拷贝 `copy/a.txt`（相同）
- `b.txt` 和 `c.txt` 同样大小但内容不同
- 一个空文件

运行：`python dupfind.py 该临时目录`

预期：只报告 `a.txt` 那一组；空文件和内容不同的文件不出现。跑完删掉临时目录。
